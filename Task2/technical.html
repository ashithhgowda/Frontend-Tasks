Core Network Protocols

The Internet functions as a "Network of Networks" using a common set of rules known as the Internet Protocol Suite. While often used interchangeably, the OSI 7-Layer Model and TCP/IP Model provide different conceptual abstractions for how data flows from an application to the physical wire.

The OSI model is a theoretical framework used to understand and design network communications, whereas the TCP/IP model is the practical, simplified implementation used in modern networking.

Key Distinction

"The OSI model defines functions; the TCP/IP model defines protocols."

Global Connectivity

The Submarine Backbone

Over 99% of international data is transmitted via submarine communications cables. These fiber-optic arteries are laid across the ocean floor, connecting continents with speeds exceeding several hundred Terabits per second. Unlike satellite links, these physical cables offer significantly lower latency and higher bandwidth density, forming the true physical foundation of the global internet.

Cybersecurity Basics

The TLS 1.3 Handshake

Securing the internet requires robust encryption during transit. The TLS (Transport Layer Security) handshake is the process where client and server negotiate encryption keys.

  1. Client Hello: Proposes cipher suites and sends random nonce.
  2. Server Hello: Selects cipher and sends digital certificate.
  3. Authentication: Client verifies certificate with Root CA.
  4. Key Exchange: Ephemeral keys are generated for session encryption.
